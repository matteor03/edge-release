# EdgeRelease

Prototype and market-validation landing page for a local-first Solid Edge release QA workflow.

Current prototype scope:
- release preflight checks
- missing/outdated drawing detection concept
- sheet-metal flat pattern readiness
- required property and revision consistency checks
- PDF/DXF/STEP/BOM release-pack concept
- local-first positioning: CAD files stay on the workstation

All demo project data is fictional and contains no employer/customer information.
