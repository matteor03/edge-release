THE PROBLEM

Export automation saves clicks. Release QA prevents expensive mistakes.

A PDF existing does not mean the drawing is current. A DXF existing does not mean the flat pattern is valid. A BOM existing does not mean the metadata is complete.

EdgeRelease is designed around one question: “Is this assembly genuinely ready to hand to manufacturing?”

V1 PRE-FLIGHT

Five checks worth paying for.

Focused on failure modes that create rework, scrap, production delays or embarrassing supplier calls.

01

Missing drawing

Flags components that require a drawing but have no associated Draft before release.

02

Out-of-date views

Detects drawings whose model views are stale before they become released PDFs.

03

Flat pattern readiness

Checks sheet-metal parts for usable, current flat patterns before DXF generation.

04

Required properties

Validates Part Number, Description, Material and company-defined mandatory fields.

05

Revision consistency

Finds mismatches between model, drawing and release naming before files leave engineering.

→

Then release

Generate PDFs, DXFs, STEPs, BOM and a release report into one structured package.
